# AutoCare

## Vision

AutoCare is an AI-powered vehicle maintenance platform that helps users manage their vehicles, maintenance history, service schedules, and receive intelligent maintenance recommendations.

## Objectives

- Simplify vehicle maintenance
- Predict upcoming maintenance
- Organize service history
- Provide AI-powered recommendations
- Store vehicle records securely

## Target Users

- Individual vehicle owners
- Car enthusiasts
- Families with multiple vehicles

## Technology Stack

Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

Backend

- FastAPI
- MongoDB

AI

- OpenAI / Gemini
